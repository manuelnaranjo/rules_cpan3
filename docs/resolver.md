# Fast Bulk CPAN Dependency Resolver & Lockfile Generator

The `rules_cpan` resolver is a high-performance dependency resolution and lockfile generation tool that consumes user dependency specifications (e.g. `deps.txt`) and resolves the minimal transitive dependency closure using CPAN mirror indices and MetaCPAN bulk APIs.

## Features

- **Standard `deps.txt` Input Format**: Accepts distribution or module names with optional version specifications (e.g. `ack v3.4.0`, `Action-Retry 0.24`, `Compress-Raw-Zlib 2.226`, `Algorithm::Diff`).
- **High-Performance CPAN Mirror Indexing**: Fetches and parses `02packages.details.txt.gz` (mapping 260,000+ packages to upstream distributions) in milliseconds with local caching.
- **Bulk MetaCPAN Querying**: Batches distribution metadata lookups against MetaCPAN's Elasticsearch API (`/v1/release/_search`), reducing hundreds of roundtrips into a handful of bulk requests.
- **Full Transitive Dependency Closure**: Recursively resolves all dependency phases (`runtime`, `build`, `configure`, and `test`) while automatically filtering built-in Perl core modules.
- **Concurrent Checksum & XS Detection**: Parallel download workers verify SHA256 checksums and inspect tarball archives for `.xs` / C extension files to accurately mark distributions as pure Perl vs. XS.
- **Deterministic, Human-Readable Lockfile (`cpan.lock.json`)**: Emits a sorted, predictable JSON lockfile conforming to `cpan/cpan.lock.schema.json`.

## Usage

### Running via Bazel

The resolver can be invoked directly from the workspace root:

```bash
INVOCATION_ID=$(uuidgen)
echo "Invocation ID: ${INVOCATION_ID}"
bazel run --invocation_id=${INVOCATION_ID} //tools:resolver -- --input deps.txt --output cpan.lock.json
```

Or using the canonical target:

```bash
INVOCATION_ID=$(uuidgen)
echo "Invocation ID: ${INVOCATION_ID}"
bazel run --invocation_id=${INVOCATION_ID} //cpan/tools/resolver:resolver -- --input deps.txt --output cpan.lock.json
```

---

## Dependency Input Format (`deps.txt`)

Each line specifies a distribution or module name, followed by an optional version constraint. Comments start with `#` and blank lines are ignored:

```text
# Production dependencies
Algorithm-Diff 1.201
Compress-Raw-Zlib 2.226

# Module names and version prefixes
Algorithm::C3 >= 0.10
ack v3.4.0

# Without explicit version (resolves to latest on CPAN)
Capture::Tiny
```

## Lockfile Specification (`cpan.lock.json`)

The lockfile contains the complete transitive closure needed to build and run the requested packages hermetically in Bazel:

```json
{
  "$schema": "https://raw.githubusercontent.com/manuelnaranjo/rules_cpan3/main/cpan.lock.schema.json",
  "comment": "Auto-generated by rules_cpan resolver. DO NOT EDIT DIRECTLY.",
  "lock_version": "1.0.0",
  "root_dependencies": [
    "Algorithm-Diff 1.201",
    "Compress-Raw-Zlib 2.226"
  ],
  "distributions": {
    "Algorithm-Diff": {
      "version": "1.201",
      "url": "https://cpan.metacpan.org/authors/id/R/RJ/RJBS/Algorithm-Diff-1.201.tar.gz",
      "sha256": "0022da5982645d9ef0207f3eb9ef63e70e9713ed2340ed7b3850779b0d842a7d",
      "is_xs": false,
      "provides": [
        "Algorithm::Diff",
        "Algorithm::Diff::_impl"
      ],
      "dependencies": {
        "build": [
          "ExtUtils-MakeMaker"
        ],
        "configure": [
          "ExtUtils-MakeMaker"
        ],
        "runtime": [],
        "test": []
      }
    },
    "Compress-Raw-Zlib": {
      "version": "2.226",
      "url": "https://cpan.metacpan.org/authors/id/P/PM/PMQS/Compress-Raw-Zlib-2.226.tar.gz",
      "sha256": "80dc104a733976eba40dbe9272cd32ebf183195204e0bdd30e214a37d2ac42cb",
      "is_xs": true,
      "provides": [
        "Compress::Raw::Zlib"
      ],
      "dependencies": {
        "build": [
          "ExtUtils-MakeMaker"
        ],
        "configure": [
          "ExtUtils-MakeMaker"
        ],
        "runtime": [],
        "test": []
      }
    }
  }
}
```

### Key Properties

| Property | Description |
| :--- | :--- |
| `version` | Exact distribution version on CPAN. |
| `url` | Canonical upstream archive URL. |
| `sha256` | SHA256 checksum of the archive. |
| `is_xs` | `true` if archive contains XS / C / C++ extensions, `false` for pure Perl. |
| `provides` | Array of all Perl modules and packages exposed by this distribution. |
| `dependencies` | Transitive dependencies on other distributions categorized by phase (`build`, `configure`, `runtime`, `test`). |

## Command Line Options

| Flag | Default | Description |
| :--- | :--- | :--- |
| `-i`, `--input` | *(Required)* | Path to input dependency file (`deps.txt`). |
| `-o`, `--output` | `cpan.lock.json` | Path to output lockfile. |
| `--cpan-mirror` | `https://cpan.metacpan.org` | CPAN mirror URL for mirror index and fallback downloads. |
| `--metacpan-api` | `https://fastapi.metacpan.org/v1` | MetaCPAN API URL for bulk release queries. |
| `--cache-dir` | `~/.cache/rules_cpan` | Cache directory for mirror index and downloaded archives. |
| `--no-cache` | `false` | Disable disk caching. |
| `--no-verify-checksums` | `false` | Skip downloading archives for SHA256 verification and XS detection. |
| `--workers` | `16` | Number of concurrent download and query workers. |
| `--phases` | `runtime,configure,build,test` | Phases to include in transitive dependency resolution. |
| `--dry-run` | `false` | Print generated lockfile to stdout without writing to disk. |
| `-v`, `--verbose` | `false` | Enable verbose logging. |
